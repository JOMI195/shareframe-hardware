# shareframe-hardware

Buildroot-based embedded Linux image for the Shareframe-Board (Raspberry Pi
Zero W): a networked e-paper photo frame. Builds the complete SD card image
including the firmware, with signed A/B over-the-air updates (RAUC + tryboot).

Related repos:

- [shareframe-board](https://github.com/JOMI195/shareframe-board) — C++ firmware and local web dashboard
- [shareframe](https://github.com/JOMI195/shareframe) — server backend and web frontend
